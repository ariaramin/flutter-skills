# Test Before Deploy - AI Agent Skill

A reusable skill derived from the two-page **“34 Test Before Deploy”** PDF.

## What it does

The skill turns the source's 34-test taxonomy into operational behavior for an AI coding/QA agent. It can:

- classify release risks;
- select relevant test categories rather than blindly requiring all 34;
- build source-aware pre-deployment test plans;
- review CI/CD and repository test coverage;
- distinguish Smoke, Sanity, Regression, System, E2E, UAT, performance, UI, security, and production-readiness concerns;
- expose unverified or blocked test areas;
- produce a defensible release-readiness recommendation.

## Source fidelity

The source PDF is a taxonomy, not a complete methodology. The skill therefore marks operational reasoning as inference and never invents missing thresholds, security procedures, environment matrices, recovery objectives, or acceptance criteria.

## Source

`34-Test-Before-Deploy.pdf`, 2 pages.

- Page 1: Main Tests + Quality & Performance Tests.
- Page 2: UI & User Experience Tests + Security Tests + Production Tests.
