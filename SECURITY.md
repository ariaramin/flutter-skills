# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub’s private vulnerability reporting feature when it is enabled for this repository.

Include a clear description, affected skill archive and version, reproduction steps, potential impact, and any proposed mitigation. Avoid including real secrets or personal data in the report.

## Scope

Reports are especially useful for guidance that could expose credentials, weaken application security, mishandle untrusted content, or create unsafe release practices. Skills are instructional content, so report inaccurate or risky advice even when it does not affect executable code.

Maintainers will review reports, confirm scope, and coordinate an appropriate update or disclosure.
